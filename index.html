Multivariable Calculus: Core Concepts

1. What is an Affine Function? g(x) = f(a) + Df(a)(x - a)

An Affine Function is a linear transformation shifted by a constant vector. In calculus, the affine function g(x) is the best first-order linear approximation (tangent plane) of f(x) near point a.

Near a, the error |f(x) - g(x)| approaches zero much faster than ||x - a||. In 3D, the graph of z = g(x) is the tangent plane!

2. What is the Normal Line?

The Normal Line is the line passing through point a perpendicular (at 90 degrees) to the tangent line or tangent plane:

  • In 2D (Level Sets): The level curve has tangent direction T = ⟨-fy, fx⟩. The normal line points along the gradient ∇f = ⟨fx, fy⟩. Because T · ∇f = 0, the gradient is strictly perpendicular (at 90°) to the tangent line!
  • In 3D (Surface): The normal line is the 3D line perpendicular to the tangent plane, pointing along n = ⟨-fx, -fy, 1⟩.

3. Derivative Matrix [1 × n] vs Gradient [n × 1]

The total derivative Df(a) is a linear map from ℝⁿ → ℝ represented as a 1 × n row matrix: [ ∂f/∂x₁ ∂f/∂x₂ ]. The gradient ∇f(a) = (Df)ᵀ is the transpose (a column vector in ℝⁿ) pointing in the direction of steepest ascent.
